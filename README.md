# Statigami

Statigami is a collection of data projects exploring interesting, unusual, and meaningful patterns in sports and everyday life.

Inspired by *scorigami*, the goal is simple: find questions that make you stop and think, then use data to figure out what is actually going on.

Projects range from quick statistical investigations to predictive modeling, Bayesian analysis, machine learning, and data visualization.

## What I Explore

Some of the questions behind Statigami include:

- How unusual was that game or performance?
- When does an early-season trend become meaningful?
- Which statistics actually predict winning?
- Where does the data disagree with conventional wisdom?
- How much uncertainty is hiding behind a simple percentage?
- Can we predict what happens next?
- What interesting patterns exist outside of sports?

Sports are the main playground, but Statigami can also include health, behavior, everyday life, and other areas where data tells an interesting story.

## Project Structure

Each investigation lives in its own folder.

Projects stay intentionally lightweight and may include:

```text
project-name/
├── analysis.R
├── README.md
├── data/
└── figures/
```

Not every project needs every folder. The goal is to keep the workflow simple enough to move quickly from an interesting question to an answer.

## Tools

Most projects use some combination of:

- R
- tidyverse
- ggplot2
- Python
- SQL
- APIs and public sports datasets
- statistical modeling
- Bayesian methods
- machine learning

The specific tools depend on the question.
